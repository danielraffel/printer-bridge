Printer Bridge

Printer Bridge is a macOS utility that helps keep older printers useful by enabling AirPrint for printers that already work with a modern Mac.

  • If your Mac can already print to it but it does not support AirPrint, Printer Bridge will usually make it available to iPhone, iPad, and other Apple devices.
  • Universal macOS installer for Intel and Apple Silicon
  • No analytics, no tracking, no ad network, and no data resale
